==============================================================================
SECTION 1 - WHAT YOU ARE BUILDING
==============================================================================

An MCP (Model Context Protocol) server that lets Claude answer Pune commute
questions by calling real tools, for example:

  "Which bus stops are near Pimpri station?"
  "When is the next bus from the Shivajinagar stop towards Hinjewadi?"
  "What are the first and last metro trains from Swargate?"
  "Best way from home to college, leaving at 8:30 am?"

Two goals:
  (a) A working, demo-able server.
  (b) A real understanding of MCP: tools, resources, prompts, the initialize
      handshake, stdio and Streamable HTTP transports, schemas, testing and
      security.

SCOPE (v1): Pune only. Read-only except for saving places. No booking, no
payments, no custom client app.

TECHNICAL ARCHITECTURE (text version)

   Claude Desktop (stdio)            Claude connector (HTTPS)
          |                                    |
   StdioServerTransport              Streamable HTTP + Bearer Auth
          \                                    /
           +------------- MCPServer ----------+
              tools | resources | prompts | Pydantic validation | typed errors
                                |
                    services/ (pure Python)
          places.py  stops.py  departures.py  planner.py
                                |
        +-----------+-----------+------------+----------------+
     SQLite      metro.json   Maps API     GTFS-RT feed
  (sqlite3)       (Pydantic-  (httpx +      (optional,
                  checked)     cache)        stretch)

  Cross-cutting: env config, logging to stderr, pytest tests, MCP Inspector.
